# How to get YouTube transcripts with Python

Get the transcript of any YouTube video, or of a whole channel, playlist or search, as plain text
or timestamped segments, from Python, JavaScript or curl, through the
[YouTube Transcript Scraper & API](https://apify.com/pikoulas/youtube-transcripts) on Apify.

## Why a hosted API?

A library such as `youtube-transcript-api` runs on your own machine, and you keep it, its
dependencies and whatever it runs on up to date. The Actor is hosted: no server, library upkeep or
proxies of your own to run. You send video URLs to an API and get transcripts back as JSON, at $1
per 1,000; videos without captions cost nothing.

Code already written for `youtube-transcript-api` moves over with one import line through
[youtube-transcript-cloud](https://github.com/Spyridon-Pikoulas/youtube-transcript-cloud), a client
with the same interface, a CLI and an MCP server.

## Step by step

1. Sign up at [apify.com](https://apify.com) (the free plan covers a first run) and copy your API
   token from **Settings → API & Integrations**.
2. `pip install apify-client`
3. Run:

```python
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("pikoulas/youtube-transcripts").call(logger=None, run_input={
    "videos": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ"],  # URLs, youtu.be links, Shorts or IDs
    "languages": ["en"],
})
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item["title"])
    print(item["text"])
```

## A whole channel, playlist or search

```python
run_input = {
    "channels": ["@lexfridman"],             # URLs, @handles or channel IDs: the latest uploads
    "playlists": ["https://www.youtube.com/playlist?list=YOUR_PLAYLIST_ID"],
    "searchQueries": ["how to bake sourdough"],
    "maxVideosPerSource": 20,
    "publishedAfter": "2026-01-01",
}
```

[`python/youtube_channel_to_markdown.py`](../python/youtube_channel_to_markdown.py) saves a
channel's latest videos as Markdown files, one per video, ready for a RAG pipeline.

## Options that matter

| Input | What it does |
|---|---|
| `languages` | Caption languages to prefer, in order (`["en", "es"]`). The first one a video has wins. |
| `includeTimestamps` | Adds `segments`: each caption line with its start and end in seconds. |
| `subtitleFormats` | `["srt", "vtt"]` saves subtitle files and links them from each row. |
| `onlyNew` | For a scheduled run: each channel, playlist or search gives only videos it hasn't given before. |

## FAQ

**A video has no captions.** Its row comes back with an `error` and costs nothing.
[Video to Text](https://apify.com/pikoulas/video-transcriber) transcribes its speech with Whisper
from the same URL, at $0.003 a minute ([guide](../video-to-text/README.md)).

**Can an AI agent use it?** Yes, through Apify's MCP server: see the
[main README](../README.md#use-them-from-ai-agents-mcp).

**Other platforms?** [TikTok](../tiktok/README.md), [Instagram Reels](../instagram/README.md),
[podcasts](../podcasts/README.md) and [any other video or audio URL](../video-to-text/README.md).
