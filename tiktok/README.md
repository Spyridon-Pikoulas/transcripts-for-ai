# How to get TikTok transcripts

Get what is said in TikTok videos as text, by video URL, a creator's profile, a hashtag or a
search, from Python, JavaScript or curl, through the
[TikTok Transcript Scraper](https://apify.com/pikoulas/tiktok-transcripts) on Apify. No TikTok
account, no browser.

The transcripts are TikTok's own captions, in every language a video has them, at $1 per 1,000.
For videos without captions, turn on `speechToText`: OpenAI's Whisper transcribes them inside the
run, at $0.003 a started minute.

## Step by step

1. Sign up at [apify.com](https://apify.com) (the free plan covers a first run) and copy your API
   token from **Settings → API & Integrations**.
2. `pip install apify-client`
3. Run:

```python
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("pikoulas/tiktok-transcripts").call(logger=None, run_input={
    "videos": ["https://www.tiktok.com/@nasa/video/7689547576265149710"],  # URLs, short links or IDs
    "profiles": ["nasa"],                  # a creator's latest videos
    "maxVideosPerProfile": 10,
    "hashtags": ["sourdough"],
    "searchTerms": ["sourdough bread"],
})
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item["url"], item["views"], item.get("text"))
```

[`python/tiktok_profile.py`](../python/tiktok_profile.py) prints a creator's latest videos with
their views, opening hook and transcript.

## Options that matter

| Input | What it does |
|---|---|
| `speechToText` | Transcribes videos without captions with Whisper (`speechModel`: `base` or the more accurate `small`). |
| `languages` | Caption languages to prefer, in order, where a video has more than one track. |
| `publishedAfter` | Only videos posted since a date. |
| `onlyNewVideos` | For a scheduled run: each profile gives only the videos posted since the last run. |
| `includeTimestamps`, `includeSrt`, `includeVtt` | Timestamped segments, and subtitle files. |

`hook` is what is said in the first seconds: the line that keeps viewers watching.

## FAQ

**A video has no transcript.** Without `speechToText`, a video TikTok has no captions for comes
back with its details and a `noTranscriptReason`, free.

**Can an AI agent use it?** Yes, through Apify's MCP server: see the
[main README](../README.md#use-them-from-ai-agents-mcp).

**Other platforms?** [YouTube](../youtube/README.md), [Instagram Reels](../instagram/README.md),
[podcasts](../podcasts/README.md) and [any other video or audio URL](../video-to-text/README.md).
